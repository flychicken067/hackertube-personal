# HackerTube 功能一致性规格

## 目标

在不复制 HackerTube 源码、不爬取、不增加账号系统的前提下，使本项目与 https://hackertube.org/ 当前公开版在核心使用体验上一致，同时保留本项目的 Karpathy 专区和个人数据导入导出。

## 公开数据边界

- 只使用 HackerTube 在 https://hackertube.org/data 发布的 ODC-By 1.0 导出。
- 数据基线：6,454 个视频、39,834 条 HN 评论、150 个话题、16 个领域、3,778 个视频的关联推荐。
- YouTube 播放量、时长和发布日期不在导出中；只能通过用户自己的 YouTube Data API 密钥补全。
- 不将 API 密钥写入代码、数据文件或 Git 历史。

## 一致性验收项

1. 首页包含 HN 经典、冷门佳作、近期收录、尚未探索话题、与点赞相似、同一批 HN 用户也推荐的内容，并显示选中理由；浏览页支持上传年代、类型、时长、冷门佳作、长期有效与排序筛选。
2. 搜索支持标题、频道、标签、话题描述与同义表达，并使用公开导出的 384 维向量和同款 BGE 模型完成真正的语义检索，不要求标题包含原词。
3. 视频页按需加载并展示所有公开导出的 HN 评论，包含作者、故事标题、立场、评论文本和 HN 链接。
4. 视频页合并展示来自 related.jsonl 的“HN 用户也推荐”和官方向量计算出的相似视频。
5. 支持点赞、不喜欢、稍后看、历史和键盘快捷键，反馈会改变首页排序。
6. 默认显示 YouTube 中段帧，设置中可切换为上传者默认缩略图。
7. YouTube 元数据脚本从环境变量读取 API 密钥，支持断点续跑、配额失败和缓存。
8. 整站不要求登录；个人状态仅保存在浏览器，并支持导入、导出和清空。
9. 保留 37 条 Karpathy 官方视频、播客和演讲，不污染 HN 数据统计。
10. 保持纯静态 GitHub Pages 部署；大文件按需加载，首页不得一次下载全部评论。

## 完成定义

- 上述 10 项均有自动化测试。
- npm run check 和 Playwright 端到端验收全部通过。
- 与 HackerTube 当前公开页面逐项浏览器对照。
- 推送 main，GitHub Pages 工作流成功，线上页面无控制台错误。
- README 说明数据许可、更新方式、YouTube API 密钥配置和部署。
